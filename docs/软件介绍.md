# 宇额助手（CS2 余额助手）软件介绍

> 版本：v1.5.5（已打包，versionCode 21）｜ 包名：`com.cs2balance.assistant` ｜ 平台：Android（minSdk 24）
> 说明：早期名为「CS2 余额助手 / CS2 余额雷达」，v1.4.4 起更名「宇额助手」。

## 1. 一句话定位

**纯手机端 Android App**：监控 CS2 武器箱行情，发现「C5GAME 低价买入 → 约 7 天交易保护期 → Steam 市场卖出」的套利机会，并管理自己的库存与买入记录。**所有分析都在手机本地完成**（快照 → 预测 → 收益 → 雷达 → 模拟），不依赖自建服务器。

## 2. 核心功能

| 功能 | 说明 |
|---|---|
| 📡 一键扫描 | 从 Steam 市场热门武器箱榜单（回退成交量榜）拉取候选，批量查 C5GAME 买入价，逐个拉 Steam 实时价，写入本地快照；支持断点续采（15 分钟内跳过已采）、采集数量 1-100 自选 |
| 📊 市场行情 | 每个箱子的最新 Steam 价 / C5 买入价 / 预计几折 / 近 7 天与 90 天走势图 |
| 🎯 雷达信号 | 综合评分与买卖信号（7 天预测 P50/P25 对买入价的收益与风险），事件日历（Steam 大促 / Major / 春节行情）修正评分 |
| 📦 库存同步 | 用 **Steam Web API（官方 IEconService）** 拉取本人库存，双 Context（普通 + 交易保护）合并，自动导入本地库存并精确到小时的解锁倒计时 |
| 🔁 快速导入历史（C5） | 借鉴 C5GAME 网页趋势接口，一键登录 C5 后批量导入各箱 90 天官方价格历史（约 120 个价格点） |
| 💰 买入记账 | 本地记账买入（核验预算/限制期/二次确认），生成订单流水；待 C5 官方开放下单接口后接入自动下单 |
| 🧮 模拟器 | 按预算与分配策略模拟买入组合的收益/风险；反向模拟（目标收益推预算） |
| 🔐 一键登录 | App 内嵌 WebView 登录 Steam / C5GAME，自动抓取并保存 cookie；Steam 支持手填 Web API Key + SteamID64 |

## 3. 页面结构

- **首页**：一键扫描、快速补历史、快速导入历史入口、市场分析摘要
- **市场**：行情列表 / 详情（走势、预测、买卖时机、C5 求购参考、Skinport 实际成交参考）
- **库存**：本地库存、Steam 同步入口、解锁倒计时、卖出建议
- **雷达**：信号列表（按评分排序，标注风险/流动性/事件窗口）
- **我的（设置）**：采集数量、C5 app-key、Steam/C5 Cookie、Steam Web API Key、SteamID64、一键登录入口

## 4. 所需配置（按用途）

| 配置 | 用途 | 获取方式 |
|---|---|---|
| C5 app-key（选填） | 批量查 C5 买入价、查 itemId、求购价 | C5 开放平台申请（opendoc.c5game.com） |
| Steam Cookie（选填） | 提高搜索榜返回数量、库存会话兜底 | App 内「Steam 一键登录」自动保存 |
| C5 Cookie（选填） | **快速导入历史**（C5 官方趋势接口必须登录态） | App 内「C5 一键登录」自动保存 |
| Steam Web API Key + SteamID64（库存推荐） | **库存同步唯一推荐通道** | steamcommunity.com/dev/apikey 免费申请；ID 可填自定义 URL 自动解析 |

## 5. 技术栈与架构

- React Native（Expo 开发、Android 原生打包）、Hermes 引擎、TypeScript
- 数据全部本地化：`AsyncStorage` 快照库（`@cs2balance/snapshots_v2`）→ 本地分析引擎（预测器 baseline-momentum-v2 / 事件日历 V3、收益计算、雷达、模拟）
- 数据源只用 **Steam 官方接口** + **C5GAME 官方/网页接口**（详见《数据调用链路.md》）
- 版本策略：每次新版本三处版本号同步（package.json / app.json / build.gradle），版本记录见 `docs/HANDOFF.md`

## 6. 已知限制

- Steam 历史 `pricehistory` 接口需登录 cookie，且在该类网络环境下不稳定 → 主通道已切换到 C5 官方趋势
- C5「买入价」为在售最低价快照，非实时成交价
- 一键买入目前为本地记账，不自动下单
- 库存同步需公开库存 / 本人 SteamID64；Steam Web API 对第三方可能不返回交易保护期资产（已做完整诊断文案）
