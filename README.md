# 宇额助手（CS2 余额助手）

纯手机端 Android App：监控 CS2 武器箱行情，发现「C5GAME 低价买入 → 约 7 天交易保护期 → Steam 市场卖出」的套利机会，本地完成采集 / 分析 / 预测 / 雷达 / 库存管理 / 买入记账，不自动买卖、不连电脑。

- **当前版本**：v1.9.5（versionCode 43，Local-First）→ `releases\宇额助手-v1.9.5.apk`
- **唯一文档**：**`docs/HANDOFF.md`** —— 项目定位、功能、数据调用链路、构建发版流程和版本记录全部在此，接手前必读
- **目录**：`mobile/` 唯一运行主体；`backend/` 离线历史参考与 `verify:core` 基准（勿删）；`releases/` APK 产物

当前运行链路固定为：手机 SQLite → 安装包历史种子 → Steam 官方直连 → C5 OpenAPI。普通页面打开和下拉刷新只读本地数据；一键扫描、详情刷新和市场页“更新实时盘口 / 机会”才会发起实时请求。所有预测、机会决策和持仓数据均在手机本地计算与保存。

> 所有对外解释必须简体中文；新版本发布后必须回写 docs/HANDOFF.md 并同步桌面副本 APK（详见 HANDOFF 第 9.1 节发版流程）。
